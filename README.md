# Fortran Space Invaders

A classic Space Invaders-style arcade game implemented using GNU Fortran.

## Features
- Player movement
- Shooting mechanics
- Alien movement and collision detection
- Score tracking
- Three lives
- Restart functionality

## Controls

| Key | Action |
|---|---|
| A | Move left |
| D | Move right |
| Space | Shoot |
| Q | Quit |
| R | Restart |

## Requirements
- GNU Fortran (gfortran)
- Windows console with ANSI escape support

## How to Run

Compile:

```bash
gfortran main.f90 -o space_invaders.exe
```

Run:

```bash
space_invaders.exe
```
